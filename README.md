# AjudaBetha: Integração Contábil (Tributos x Contábil)

Material de orientação para a prestação de contas 2027 (e-Sfinge / SIM-AM). Base: comunicado Betha de 21/09/2026.

## Estrutura

| Caminho | O que é |
|---|---|
| `index.html` | Página principal: orientações, passo a passo em ordem, percentual, telas do sistema e geração de PDF. Arquivo único, pronto para GitHub Pages. |
| `apresentacao/index.html` | Apresentação navegável com fluxogramas (setas do teclado ou botões). |
| `docs/Guia_Integracao_Contabil_Tributos_x_Contabil.md` | Guia operacional em texto com checklists. |
| `assets/marca/` | Logotipo e marca reduzida (B) extraídos do Manual de Marca Betha. |
| `assets/telas/` | Telas do sistema usadas na página. |
| `.nojekyll` | Faz o GitHub Pages servir os arquivos sem processamento. |

As imagens já estão embutidas no `index.html`. A pasta `assets` serve para edição futura.

## Publicar no GitHub Pages

1. Crie um repositório público e suba o conteúdo desta pasta.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O endereço fica no formato `https://usuario.github.io/repositorio/` e a apresentação em `.../apresentacao/`.

## Observações

- Nada é salvo: ao recarregar, o passo a passo recomeça.
- O PDF é gerado no próprio navegador (jsPDF via cdnjs).
- Etapas sem tela mostram um espaço reservado. Para incluir novas telas, envie os prints com o campo a destacar.
